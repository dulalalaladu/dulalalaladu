# Hi, I'm Dr. Anyi Liu 👋

**Cybersecurity researcher and educator at Oakland University**, working at the
intersection of security and **Physical AI** — the AI systems that perceive the
world and act on it through actuators.

My research asks a simple question with hard consequences: *what happens to security
when an AI failure stops being a bad output on a screen and becomes an unsafe action
in the physical world?* I study how to defend the whole **sense → think → act** loop
of embodied systems — autonomous drones (UAVs), self-driving and connected vehicles,
robots, industrial control, and embodied LLM agents — under real-time and safety
constraints. Alongside the research, I design hands-on, interaction-first security
curricula and labs so that students learn to attack, defend, and reason about these
systems by actually running them.

---

## 🔬 Research Interests

- **Security of Physical AI / cyber-physical systems** — protecting the perception,
  decision, and control pipeline of robots, UAVs, and autonomous vehicles.
- **Embodied LLM agents** — prompt injection and untrusted-input attacks that turn
  an agent's reasoning into an unsafe physical action, and the runtime defenses that
  contain them.
- **Adversarial machine learning** — sensor/signal spoofing (incl. GPS), physical
  adversarial patches, and robust perception.
- **Anomaly & intrusion detection, IR and digital forensics** for safety-critical
  systems.
- **Malware analysis** and offensive/defensive security education (cyber ranges).
- **Cybersecurity education** — interaction-first labs, agent-native testbeds, and
  curriculum design (incl. NSF-aligned program development).

## 🎓 Teaching

I build security courses that run on *interaction* — students predict, run, observe,
explain, and redesign rather than read passively. My labs **chain** on a single
simulated testbed (stand it up → instrument it → threat-model it → attack it → harden
it → monitor it → capstone), so each week builds on a system the student already
understands.
